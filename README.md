# badger-rust

A learning port of [Badger](https://github.com/dgraph-io/badger) v4.9.6 to Rust.
It aims to stay on-disk compatible with Go Badger: each implementation can open
databases written by the other.

See [PLAN.md](PLAN.md) for the roadmap. Current status: **Phase 7 (remaining features) done**: write batches, the merge operator, iterator prefetching, streams and the stream writer, backups that load across Go and Rust in both directions, subscriptions and encryption key rotation. Next is Phase 8 (CLI and hardening).

## Layout

| Path | What |
|---|---|
| `crates/badger` | the library |
| `crates/badger-cli` | command-line tools (Phase 8) |
| `crates/badger-fixtures` | test support: loads the Go-generated fixtures |
| `compat/go-fixtures` | Go program that generates fixtures and verifies Rust-written DBs ([docs](compat/README.md)) |
| `compat/fixtures` | committed fixtures generated by Go Badger v4.9.6 |
| `compat/golden` | exact outputs of Go Badger building blocks, for byte-for-byte tests |

## Development

```sh
make check      # cargo fmt --check, clippy -D warnings, tests
make fixtures   # regenerate compat/fixtures (needs Go >= 1.24)
make golden     # regenerate compat/golden
make miri       # unit tests under Miri (nightly)
make loom       # skiplist interleavings under loom
make compat     # build tables and DBs with Rust, verify them with Go
```
